# Калибровка slopcheck

Корпус живых OSS-репозиториев (`corpus.yml`), закреплённых на коммите. Бенч
меряет долю шума: сколько находок полезны, а сколько — ложные срабатывания.
Порог из DoD v3 — шум не больше 20% среди размеченных находок уровня warn+.

## Прогон

```bash
uv run python bench/run.py run                    # все репо: клон → slopcheck → таблица
uv run python bench/run.py run --only cobra       # один репо
uv run python bench/run.py run --docker slopcheck:dev   # тем же образом, что в CI
uv run python bench/run.py report                 # только таблица по сохранённому
```

Клоны лежат в `~/.cache/slopcheck-bench`; повторный прогон на том же коммите
сеть не трогает (кроме зависимостей Go-модулей при первом анализе).
Находки — в `bench/out/` (не коммитятся). Для локального прогона нужны все
детекторы из README slopcheck; `--docker` берёт их из образа.

## Разметка

```bash
uv run python bench/run.py label cobra --per-rule 15
```

дописывает в `labels/cobra.yml` до 15 неразмеченных находок на правило с
`verdict: "?"`. Проставьте `useful` или `noise` и одной строкой `why`.
Ключ находки не содержит номера строки, поэтому разметка переживает
пересборку корпуса; `where` — только подсказка, где смотреть.

Подтверждённый шум закрепляется тестом в `tests/noise/`: фикстура с кодом,
на котором находки быть не должно.

## Пополнение корпуса

Добавьте запись в `corpus.yml` (`name`, `url`, `commit`, опционально `path`).
Коммит берите из `git ls-remote <url> HEAD` и не двигайте без причины:
сдвиг коммита меняет находки и обесценивает разметку.
